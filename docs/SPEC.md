# 小逻辑（KidLang）语言规范 v0.2

> 一门中文编程语言。语法骨架照着 C 和 Python 来，壳子是中文的。
> 实现见 `interpreter.js`（零依赖，浏览器与 Node 双端可用），界面见 `index.html`。

---

## 1. 设计取向

v0.1 是一套极简的「不写错代码」教学语言。v0.2 长出了类型系统、函数、数组、指针和文件——从「认识编程」变成「能写完整程序」。

不变的两条底线：

- **不依赖缩进，不依赖换行**。语句边界由关键字决定，整段挤成一行、缩进全乱、Tab 空格混用，照跑。
- **没有 `=`、没有 `==`、没有 `{ } ; :`**。赋值说「定义 / 把…改成」，比较说「等于」。C 语言初学者最经典的 `=` 与 `==` 混淆，在这门语言里从语法层面就不存在。

变了的地方：现在它有类型、有函数、有指针、能读写文件。可以写真正的算法了。

## 2. 类型系统

### 2.1 九种类型

| 写法 | 说明 | 例子 |
|---|---|---|
| `整型` | 整数 | `42` |
| `浮点型` | 小数 | `3.14` |
| `布尔型` | 真 / 假 | `真`、`假` |
| `字符型` | 单个字符 | `'A'` |
| `字符串` | 一串文字 | `"你好"` |
| `数组` | 一组同类型值 | `[1, 2, 3]` |
| `指针` | 指向一个变量 | `&分数` |
| `文件` | 文件句柄 | `打开文件 "a.txt" 为 写` |
| `函数` | 可调用 | —— |

### 2.2 类型可以不写

写了类型就做检查，不写就按值的类型自动推断并锁定：

```
定义 整型 年龄 是 11        # 显式：放 11.5 会报错
定义 身高 是 1.52           # 省略：自动成为浮点型
```

**类型检查是运行时的、宽容的**：整型变量收到 `"42"` 这样的文字会自动转成数字，但收到 `3.5` 会直接拒绝：

```
定义 整型 年龄 是 11.5
→ 「年龄」是整型，不能放小数 11.5
   想放小数请用「定义 浮点型」
```

### 2.3 类型转换

```
整型(3.9)        → 3
浮点型("2.5")    → 2.5
字符串(123)      → "123"
布尔型(0)        → 假
```

## 3. 词法

### 3.1 关键字

**硬关键字**（不能当变量名）：

```
定义 把 给 说 输出 输入 如果 否则 当 做 对于 结束 结束当 停 返回 参数 指向
非 与 或 真 假
大于 小于 等于 不等于 大于等于 小于等于
加上 减去 乘以 除以 整除 取余 乘方
随机 绝对值 长度 余数 地址 取地址 打开文件 写 读 关闭 追加
整型 浮点型 布尔型 字符型 字符串 数组 指针 文件 函数
或者如果
```

**软关键字**（按位置识别，可以出现在变量名里）：

```
是 时 次 从 到 步长 为
```

所以「时间」「从来」「为什么」「次数」都能正常当变量名：

```
定义 时间 是 12
定义 为什么 是 "因为"
输出 时间 + 1
```

### 3.2 标识符

汉字、英文字母、数字、下划线组成，不能以数字开头。**中文名和英文名完全等价**：

```
定义 count 是 0
定义 计数器 是 0
给 count 加上 1
给 计数器 加上 1
```

### 3.3 字面量

```
42        整数
3.14      小数
"你好"    文字（也认 “你好” 和 「你好」）
'A'       单个字符
真 假      布尔值
[1,2,3]   数组
```

### 3.4 标点宽容

全角标点自动归一，不用切输入法：

```
（ ）［］ ＋ － ＊ ／ × ÷ ％ ， 、
```

数组里用中文逗号 `[1，2，3]` 也认。

字符串与字符内部的标点原样保留——`输出 "你好，世界"` 里的逗号不会被吃掉。

### 3.5 注释

`#` 到行尾。

## 4. 语句

### 4.1 定义与赋值

```
定义 [类型] 名字 是 表达式     定义变量
把 名字 改成 表达式            重新赋值
给 名字 加上|减去|乘以|除以 表达式   累加
```

赋值目标可以是变量、数组元素或指针指向的东西：

```
把 分数 改成 95
把 数组[0] 改成 100
把 *p 改成 200
```

### 4.2 输入输出

```
输出 表达式
说 表达式            # 同义
输入 "提示语"         # 返回文字
输入 整型 "提示语"    # 带类型转换
```

### 4.3 分支

```
如果 条件
    ...
或者如果 条件
    ...
或者如果 条件
    ...
否则
    ...
结束
```

`或者如果` 和 `否则` 都可以省略。命中第一个成立的分支后，后面的不再判断。

### 4.4 三种循环

```
# 计数循环（for）
对于 i 从 1 到 10
    ...
结束

对于 i 从 1 到 10 步长 3      # 不写步长默认是 1（起点大于终点时自动 -1）
```

```
# 条件循环（while）
当 条件
    ...
结束
```

```
# 先执行后判断（do-while）
做
    ...
结束当 条件
```

> do-while 用 `结束当` 收尾，而不是单独的 `当`。原因：`做` 的循环体里可能嵌套一个 `当` 循环，单独用 `当` 会产生歧义（分不清是循环体的开始还是 do-while 的结尾）。`结束当` 一个词把两件事都说清楚了。

循环里可以用 `停` 跳出。

### 4.5 函数

```
定义 函数 名字 参数 a b
    ...
    返回 a + b
结束
```

参数可以标注类型：

```
定义 函数 平方 参数 整型 x
    返回 x * x
结束
```

调用就是 `名字(参数, 参数)`。没有 `返回` 的函数返回空。

**作用域是词法的**：函数体能看到定义处的变量，看不到调用处的。递归正常工作。

### 4.6 数组

```
定义 数组 分数 是 [92, 78, 85]
定义 数组 空格子 长度 5          # 5 个 0

输出 分数[0]
把 分数[1] 改成 100
输出 长度 分数
```

支持多维：`定义 数组 m 是 [[1,2],[3,4]]`，取 `m[1][0]`。

下标越界会报错并说明原因：`数组只有 3 个元素，取不到第 5 个`。

数组和文字都支持负索引和切片，见 4.9。

### 4.7 指针

```
定义 整型 分数 是 90
定义 指针 p 是 &分数          # 或者：定义 指针 p 指向 分数

输出 *p                       # 顺着指针读到 90
把 *p 改成 100                # 通过指针改，分数变成 100
输出 地址 分数                 # 0x1000
```

指针记录的是「哪个作用域里的哪个变量」，所以能穿进函数里改外层的变量。

### 4.8 文件

```
定义 文件 f 是 打开文件 "成绩.txt" 为 写
写 f "小明 92"
写 f "小红 88"
关闭 f

定义 文件 g 是 打开文件 "成绩.txt" 为 读
定义 字符串 行 是 读 g
当 行 不等于 ""
    输出 行
    把 行 改成 读 g
结束
关闭 g
```

打开模式有三种：`读`、`写`（清空后写）、`追加`。`读` 每次返回下一行，读到末尾返回空字符串。

文件系统是**虚拟的**：浏览器里跑在内存 + localStorage 上，不碰真实磁盘，界面上能看到文件内容。Node 环境下可以接真实 fs。

### 4.9 字符串与切片

字符串沿用 Python 的用法：索引、切片、方法。

**索引**从 0 开始，负数从末尾数：

```
定义 字符串 s 是 "Hello"

输出 s[0]        # H
输出 s[-1]       # o
输出 s[-2]       # l
```

越界会报错并说清楚有几个字符：`这段文字只有 5 个字符，取不到第 9 个`。

**切片**写成 `起点:终点:步长`，三个都可以省略，终点不含在内：

```
输出 s[0:2]      # He
输出 s[2:]       # llo
输出 s[:2]       # He
输出 s[:]        # Hello      整份复制
输出 s[::2]      # Hlo        每隔一个
输出 s[::-1]     # olleH      反转
输出 s[-2:]      # lo
```

数组用同一套规则：`a[1:3]`、`a[::-1]`。

**方法**用点号调用，可以链式：

```
输出 "abc".大写()                    # ABC
输出 "  x  ".去空白()                # x
输出 "a,b,c".分割(",")[1]            # b
输出 "1,2,3".分割(",").长度()        # 3
```

字符串方法：

| 方法 | 说明 |
|---|---|
| `长度()` | 字符个数 |
| `大写()` / `小写()` | 全部转大小写 |
| `首字母大写()` / `每个词首字母大写()` | 首字母 |
| `去空白()` / `去左空白()` / `去右空白()` | 去首尾空白 |
| `查找(子)` | 子串位置，找不到 -1 |
| `替换(旧, 新 [, 次数])` | 替换 |
| `分割([分隔符])` | 切成数组；不填按空白切 |
| `行分割()` | 按换行切 |
| `开头是(前缀)` / `结尾是(后缀)` | 判断，返回布尔 |
| `包含(子)` | 判断 |
| `出现次数(子)` | 计数 |
| `全是数字()` / `全是字母()` / `全是空白()` | 判断 |
| `补左(宽[,填])` / `补右` / `居中` | 对齐 |
| `反转()` | 倒序 |
| `去掉前缀(前缀)` / `去掉后缀(后缀)` | 去掉 |
| `字符码()` | 第一个字符的编码 |

数组方法：

| 方法 | 说明 |
|---|---|
| `长度()` | 元素个数 |
| `合并([分隔符])` | 拼成字符串 |
| `反转()` / `排序()` / `降序排序()` | 返回新数组，不改原数组 |
| `查找(值)` | 下标，找不到 -1 |
| `包含(值)` | 判断 |
| `求和()` | 数字数组求和 |
| `添加(值)` / `删除末位()` | 原地修改 |

方法名不是关键字，所以 `大写`、`查找`、`反转` 这些词仍可以当变量名用。

## 5. 运算符与优先级

由低到高：

```
1. 或
2. 与
3. 非
4. 比较：大于 小于 等于 不等于 大于等于 小于等于
5. 加减：+ -
6. 乘除：* / // %
7. 乘方：**
8. 一元：- 非 * &
9. 原子
```

### 5.1 四则运算仿 Python

| 运算 | 结果 | 说明 |
|---|---|---|
| `7 / 2` | `3.5` | 真除法 |
| `7 // 2` | `3` | 整除（向下取整） |
| `7 % 3` | `1` | 取余 |
| `-7 % 3` | `2` | 余数符号跟除数走（同 Python） |
| `2 ** 10` | `1024` | 乘方 |
| `"ab" * 3` | `"ababab"` | 文字重复 |
| `"你" + "好"` | `"你好"` | 文字拼接 |

中文写法也认：`加 减 乘 除 整除 取余 乘方`。

### 5.2 逻辑运算严格

`与`、`或`、`非` 只接受布尔值，不搞 C 那套「非零即真」：

```
如果 1 与 真        → 报错：「与」的两边都要是布尔值
如果 分数 大于 60 与 姓名 等于 "小明"    → 正确
```

这是刻意的。C 里 `if (x)` 和 `if (x > 0)` 混用是初学者错误的一大来源；强制写清楚比较，反而学得更扎实。

## 6. 执行模型

链路：**源码 → 词法 → 语法(AST) → 生成器解释器**。

解释器不一口气跑完，每执行一个语义动作就产出一份**执行快照**后挂起：

```js
{
  line: 9,
  narration: "当 [行 不等于 \"\"] → 成立，第 2 圈",
  vars: [["f", <文件>, "文件"], ["行", "小红 88", "字符串"]],
  output: ["读到：小明 92", "读到：小红 88"],
  files: [["成绩.txt", "小明 92\n小红 88\n"]],
  steps: 11
}
```

界面上的行高亮、变量盒子、文件区、旁白，全部由这份快照驱动。

**函数调用是可追踪的**：进入函数、条件判断、返回、离开，每一步都会出现在旁白里。递归不会糊成一团。

保护：单次执行上限 60000 步，递归深度上限 120 层。

## 7. 错误信息

报错是教材，不是调试信息。原则：**说人话 + 指出位置 + 给出下一步**。

| 触发 | 报错 |
|---|---|
| `定义 整型 a 是 3.5` | 「a」是整型，不能放小数 3.5 —— 想放小数请用「定义 浮点型」 |
| `定义 布尔型 b 是 1` | 「b」是布尔型，只能放「真」或「假」 |
| `定义 字符型 c 是 'AB'` | 字符型只能放一个字符，你放了 2 个 —— 想要一串文字请用双引号 |
| `输出 a[5]`（数组只有 2 个） | 数组只有 2 个元素，取不到第 5 个 —— 下标从 0 开始数 |
| `a = 1` | 这个语言里不用「=」—— 定义一个值用「定义 名字 是 值」；比较两个值用「等于」 |
| 缺 `结束` | 少了「结束」—— 「如果 / 当 / 对于 / 定义 函数」都需要收尾 |
| `输出 f(1,2)`（f 只要 1 个参数） | 函数 f 需要 1 个参数，你给了 2 个 |
| 递归不收敛 | 函数调用太深了，可能是无限递归 |

## 8. 与 C / Python 的对照

| | C | Python | 小逻辑 |
|---|---|---|---|
| 定义变量 | `int a = 1;` | `a = 1` | `定义 整型 a 是 1` |
| 赋值 | `a = 2;` | `a = 2` | `把 a 改成 2` |
| 累加 | `a += 2;` | `a += 2` | `给 a 加上 2` |
| 条件 | `if (x) {} else {}` | `if x: else:` | `如果 x / 否则 / 结束` |
| 多分支 | `else if` | `elif` | `或者如果` |
| while | `while (x) {}` | `while x:` | `当 x / 结束` |
| do-while | `do {} while (x);` | 无 | `做 / 结束当 x` |
| for | `for (i=0;i<n;i++)` | `for i in range(n):` | `对于 i 从 0 到 n-1` |
| 函数 | `int f(int a) {}` | `def f(a):` | `定义 函数 f 参数 整型 a / 结束` |
| 数组 | `int a[3];` | `a = [1,2,3]` | `定义 数组 a 是 [1,2,3]` |
| 指针 | `int *p = &a;` | 无 | `定义 指针 p 是 &a` |
| 取地址 | `&a` | 无 | `&a` 或 `取地址 a` |
| 解引用 | `*p` | 无 | `*p` |
| 输出 | `printf` | `print` | `输出` |
| 输入 | `scanf` | `input` | `输入` |

**能直接迁移走的**：优先级规则、`// % **` 的语义、`*` 和 `&` 的用法、作用域与递归、数组下标从 0 开始。

**刻意不一样的地方**：没有 `=`、没有缩进敏感、逻辑运算强制布尔、do-while 用 `结束当` 收尾。

## 10. 已知限制

- **虚拟文件系统**：浏览器里不落盘。要真实读写得接 Node 的 fs，或者在界面上加导出。
- **没有结构体/类**：数组只有同类型元素的约定，不强校验。想做「记录」得靠多个平行数组或二维数组。
- **没有字符串方法**：只有 `长度`。取子串、查找、替换都没有。
- **没有 `switch`**：用 `或者如果` 链代替。
- **数字精度**：浮点用 JS 的 double，`0.1 + 0.2` 会得到 `0.30000000000000004`（显示时截断到 8 位）。真要教浮点误差时可以拿它当例子。
- **没有编译产物**：纯解释执行，不做字节码。
